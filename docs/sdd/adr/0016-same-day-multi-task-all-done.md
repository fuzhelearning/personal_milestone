# ADR-0016: 甘特日格颜色 — 按里程碑×日聚合；未来=未开始

- Status: Accepted
- Date: 2026-08-02
- Deciders: 用户
- Related: ADR-0012（部分修正）、ADR-0015；05；preview 甘特

## Decision

### 聚合范围

- 颜色判定作用在 **某一个里程碑行 × 某一个日期** 的格子上。  
- 只统计 **属于该里程碑**、且 `plan_date = 该日` 的任务安排（可多条，如顺延叠加）。  
- **不是** Structure 总进度条；**不是**跨里程碑汇总。

### 颜色规则（相对用户时区 `today`）

| 条件 | `status` | 颜色含义 |
|------|----------|----------|
| 该里程碑该日无安排 | （空） | **无安排** |
| 该日 **> today** 且有安排 | `pending` | **未开始**（中性/待做色，**不是**未完成橙） |
| 该日 **≤ today** 且该里程碑该日任务 **全部 `done`** | `done` | **当日已全部完成** |
| 该日 **≤ today** 且有安排但 **未全部 `done`** | `not_done` | **当日有未完成**（含「多条未勾完」） |

要点：

1. 初排仍一天一事；顺延后同里程碑同日可多条。  
2. **今日及过去**：多条须全部完成 → 才从「未完成」色变为「已全部完成」色。  
3. **今日之后**：一律 **未开始**，即使已有排期，也**不得**涂成「未完成」色。

### API

`cells[]`：`date`, `planned`, `status` ∈ `done|not_done|pending`（或空），`task_ids[]`（该里程碑该日）。

## Consequences

- 修正「有安排即未完成色」的错误（未来日误涂橙）。  
- Structure 进度条不使用本规则。
