# ADR-0012: 甘特「每日进度」只展示时间安排，不展示执行状态

- Status: Accepted
- Date: 2026-08-02
- Deciders: 用户
- Related Specs: 02, 05, 09；ADR-0011（修正格语义）
- Amends: ADR-0011 §Decision #6；ADR-0007 甘特格色描述

## Context

甘特页（每日进度）若再画「已完成 / 未完成 / 待做」等执行态，与首页「今日任务」职责重叠，且干扰用户查看 AI 排出的时间安排全貌。

## Decision（已被 ADR-0016 修正）

原决定「甘特只标有无安排、不画执行态」**部分废止**。

现行（ADR-0016）：

1. 仍展示时间安排全貌（里程碑 × 日期）。  
2. 日格**恢复执行态填色**：同里程碑同日多任务须**全部 done** 才显示已完成色，否则显示**未完成**色。  
3. 勾选/原因等细操作仍在首页今日任务。  

详见 [0016-same-day-multi-task-all-done.md](./0016-same-day-multi-task-all-done.md)。
