# ADR-0013: 甘特默认窗口 — 以今天为中心，前后各 30 天

- Status: Accepted
- Date: 2026-08-02
- Deciders: 用户
- Related Specs: 02, 05；ADR-0011/0012

## Decision

1. 用户进入「每日进度 / 甘特」页时，默认日期轴为用户时区：  
   **`from = today - 30` · `to = today + 30`**（共 61 个日历日，含今天）。  
2. **视口以当前日（今天）为中心**：进入页后横向滚动，使**今天列落在可视区大致正中**（例：今天 8/3，则 8/3 出现在屏幕中部附近，而不是贴在左侧）。  
3. API `GET /gantt`：`from`/`to` 缺省时服务端按上述窗口计算并返回；客户端也可显式传参翻页/扩窗（实现可选）。  
4. 里程碑行仍展示全量阶段；窗口外日期不出现在当前轴上（扩窗后再见）。

## Consequences

- 首屏不会被远端历史/远期挤满；进入页即可对照「今天」。
