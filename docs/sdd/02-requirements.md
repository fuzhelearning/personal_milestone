## 一句话（以原型为准）

小程序首页结构：

1. **今日日期** + 右上角 **「+」**（创建目标并 AI 生成 WBS+按日安排）  
2. **Structure**：**多目标列表**；点某目标 → **改计划完成日 + 备注**并立刻重排（ADR-0014/0002）；底部入口进甘特  
3. **甘特（全局）**：当前里程碑条 + 全里程碑行日期格；today±30 居中；同日多任务须**全部完成**才不显示未完成色（ADR-0016）  
4. **今日任务**：合并所有目标；checkbox ≠ 任务行  
5. **本周剩余**：合并所有目标；**默认折叠**，点击展开  

约束：里程碑 1:N；AI 初排宜一天一事、顺延可叠加；完成日只能往后且 ≥today+3；改期不动今日安排。

```text
Structure 点目标 → 改完成日/备注 → 立刻重排未来
今日/本周 = 全目标合并；本周默认收起
```

### 今日任务点击约定（ADR-0007）

| 点击 | 效果 |
|------|------|
| checkbox | 完成 ↔ 取消勾选 |
| 任务标题行 | 展开/收起原因区 |
| 提交（未勾选） | `not_done` + 顺延；列表显示「未完成」 |

**今日任务记录字段**：`task_id, work_date, status(done|not_done), incomplete_reason?`

**本周剩余**：周=周一~周日；不含今天；只读预览（补做某过去日若需要则 P1）。

进度回写：每天 **23:59** 汇总当日 `DayEntry` → 更新 task/milestone `progress_pct`。

## 3. 明确不做

- 在 Structure 上直接拖进度当主操作

## 4. 概念对照

| 说法 | 含义 |
|------|------|
| 今日日期 | 页头，用户时区「今天」 |
| Structure 摘要 | 多目标列表；点目标改完成日/备注；底部进甘特 |
| 甘特图页 | 里程碑×日期；同日全 done 才不算未完成色（ADR-0016） |
| 今日任务 | checklist；not_done 显示「未完成」 |
| 未完成原因 | 点任务行展开；未勾选可提交；已勾选忽略 |
