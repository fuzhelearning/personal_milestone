# 讨论稿 — 请先拍板这些问题

> 完善 SDD 前，建议按优先级回答。你的答复会回填到各 Spec 的 `[DECIDE]` / `[TODO]`。

## P0（卡住模型与表结构）

1. **人在回路** — ✅ 已拍板（ADR-0001）  
   - 调完成时间 → 确认后改「尚未发生」WBS + **明日及以后**日计划；今日不动  
   - 计划已开始：完成日**只能往后、不能往回**，且新完成日 ≥ **今天+3**（ADR-0002）  
   - 提交执行偏差 → 只改日计划，WBS 总体排期不变  
   - 首次 WBS 仍需确认  

2. **结构层级** — ✅ 已拍板（ADR-0003）  
   固定两层：里程碑 → 任务。

3. **漏填日报** — ✅ 已拍板（ADR-0003）  
   催办让用户选是否完成；未完成/未选 → **周内顺延**；**周日仍未完成 → 重排**。  
   （反馈粒度：默认按「当日计划条目」选择完成与否，待你若要改再说。）

4. **日计划跨度** — ✅ 已拍板（ADR-0003）  
   排并展示**一个星期**（按日存储、按周查询；周=周一~周日）。

5. **生成接口** — ✅ 已拍板（ADR-0004）  
   **异步 + job_id 轮询**（WBS / 需 LLM 的重排均走 job）。

6. **调度** — ✅ 已拍板（ADR-0004）  
   **云定时器打 Internal API + DB 幂等**；本地用手动触发同一接口。
